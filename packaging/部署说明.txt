========================================================
NERO 真机手势控制台 免安装版 — 部署说明（目标电脑无需装 Python）
========================================================

一、部署步骤（按顺序，别跳）

1. 解压 NeroHandTwin.zip，得到 NeroHandTwin 文件夹。

2. 【关键】整个文件夹一起拷贝到目标电脑。
   ❌ 不能只拷 NeroHandTwin.exe 一个文件！
   exe 必须与 _internal 目录同级，所有依赖都在 _internal 里。

3. 【关键】放到简单路径，例如 D:\NeroHandTwin
   ❌ 避免中文、空格、& 等特殊字符的路径
   ❌ 不要放 OneDrive / 网盘同步目录（文件可能未真实下载到本地，导致 DLL 加载失败）

4. 【关键】若 zip 是网络/U盘/聊天工具传来的：先右键 NeroHandTwin.zip
   → 属性 → 勾选「解除锁定(K)」→ 确定，再解压。
   否则 Windows 会拦截 exe 和 DLL，报 DLL load failed / 找不到指定的模块。

5. 插上 RealSense D435 相机（USB 3.0 蓝色口）和 AgileX USB-CAN 适配器，
   机械臂通电、急停处于松开状态。

6. 双击 NeroHandTwin.exe：
   - 蓝色 SmartScreen 提示 → 点「更多信息」→「仍要运行」。
   - 黑色控制台打印 5 项安全确认 → 输入 yes 后回车。
   - 浏览器自动打开 http://127.0.0.1:8000 即为控制台。

7. 【更新版本后必看】如果你之前用浏览器打开过旧版控制台，浏览器可能缓存了
   旧的页面/3D 模型，导致「改了没生效」的假象。新版服务端已对静态资源发
   no-cache、并给脚本加版本号，正常情况刷新即可拿到最新画面。若仍看到旧模型：
   在控制台页面按一次 Ctrl+Shift+R（强制刷新，绕开旧缓存）即可，之后无需再按。
   验证是否已加载最新模型：3D 面板标题应显示「模型 2026-09-11-7」。

二、运行环境要求

- Windows 10 / 11 64 位（exe 已自带 Python 与全部依赖，无需任何安装）
- RealSense D435 相机 + AgileX USB-CAN 适配器 + NERO 机械臂（三者缺一不可运行，没有硬件时程序会在对应环节报错退出，这是正常现象）
- 机械臂连不上时：安装 AgileX CANdo 驱动（随 USB-CAN 附赠光盘/官网下载）

三、故障诊断（遇到问题先做这一步）

目标电脑上：Win+R → 输入 cmd → 回车，执行：
    cd /d 部署目录
    NeroHandTwin.exe --frozen-selftest

- 显示「全部通过 ✓」→ 程序包完整无损，问题在硬件、驱动或相机接线。
- 有 FAIL → 包不完整或被安全软件拦截：回到步骤 3/4 解除锁定、
  将文件夹加入杀毒软件白名单后重试。
- 双击 exe 一闪而过没有任何窗口：用 诊断启动.bat 运行，能看到具体报错。

仍无法解决：用 诊断启动.bat 运行，把控制台全部输出发给开发方。
